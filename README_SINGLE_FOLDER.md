# LiveGovtJobs — Single Folder Package

## Open this folder

Open this folder directly in VS Code/Cursor. This is the current cumulative project.

### Current source of truth

The source files directly in this root are the V4 cumulative implementation.

### Historical versions

Previous releases are included as ZIP archives directly in this same root. No separate V2/V3/V4 source folders are created.

### Normal development

Use the root project files. Do not extract the historical ZIPs unless you intentionally need an older release.
