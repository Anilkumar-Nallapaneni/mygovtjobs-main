# Fixes applied (code) vs remaining ops

This note is the go-live handoff for the wiring fixes on this branch. Nothing here invents job rows or production secrets.

## Fixed in code

- Docs that still named `supabase-auto-ingest.yml` (or `supabase-auto-ingest-self-hosted.yml`) as the daily writer now point at `.github/workflows/canonical-daily-pipeline.yml`. Source-count copy uses the registry: **171 scrapers, 164 enabled** (`scripts/scraper_registry.json`).
- `npm run build:rss` exists and runs immediately after `build:sitemap` inside `scripts/run-sync-production.py` (the script the canonical daily workflow calls). The workflow commits `frontend/public/rss.xml`. Catalog recovery does the same. The homepage links the feed, and Vercel serves it as `application/rss+xml`.
- Header **More** menu, the mobile drawer, the footer **Portals** column, the explore hub, the HTML sitemap, and `browseSeo` link the existing hub routes: `/admit-cards`, `/latest-results`, `/answer-keys`, `/upcoming-exams`, `/admission`, `/scholarships`, `/yojana`, `/designations`, `/account/bookmarks`. The signed-in account page links saved jobs.
- Push registration decodes `VITE_VAPID_PUBLIC_KEY` to bytes before `pushManager.subscribe`, and `/push-sw.js` is sent with a no-cache header.
- AdSense slots render only when `VITE_ADSENSE_CLIENT` is set **and** the placement resolves to a numeric ad-unit id (`VITE_ADSENSE_SLOT_JOB_DETAIL_MID`, `VITE_ADSENSE_SLOT_RESULTS_HUB`, `VITE_ADSENSE_SLOT_DESIGNATION_MID`).
- Homepage “official sources” count is the enabled registry size (164), regenerated by `scripts/sync-home-shell-stats.mjs` on later exports. The first-paint shell totals now match the committed `live-jobs.json` (16 notifications, 404 vacancies). They were still showing an older 36 / 15,579 shell. This does not add jobs; the catalog stays at whatever the last real export wrote.
- `VITE_ENABLE_BILLING` and `VITE_ENABLE_ADMIN_UI` stay off in `frontend/.env.example`. `AUTO_PUBLISH_VERIFIED=0` in the daily workflow is unchanged.

## Still manual (do not fake)

The committed catalog stays at the current snapshot until a real database sync. Do not hand-edit `live-jobs.json` to look larger.

1. **Supabase secrets** (GitHub Actions secrets, and matching local `backend/.env` / `frontend/.env.local`):
   - `DATABASE_URL` — transaction pooler, port **6543**, or `SUPABASE_PROJECT_REF` + `SUPABASE_DB_PASSWORD` + `SUPABASE_DB_REGION`
   - `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`
2. **GitHub Actions variable** `ALLOW_CANONICAL_PIPELINE=true`. Without it the daily workflow skips.
3. **Apply SQL** on the remote project (SQL editor or `npm run db:migrate` with `DATABASE_URL`). Migrations run through **038**, including `031_bookmarks.sql` and `032_comments.sql`. This branch does not apply SQL remotely.
4. **Sync, then promote.** `AUTO_PUBLISH_VERIFIED=0` is intentional: scrapes land as drafts. `npm run sync:production` (or Actions → **Canonical daily pipeline**) already runs `data:promote-publish-gate:apply`, which publishes only rows that pass the existing gate, then watchdog, export, sitemap, and RSS. Do not flip `AUTO_PUBLISH_VERIFIED` to bypass that gate. A narrower repair without a full scrape is `npm run p0:apply` or Actions → **Catalog recovery export**.
5. **Vercel env** (Production): `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`. Optional: `VITE_API_URL`, `VITE_GA_MEASUREMENT_ID`, `VITE_VAPID_PUBLIC_KEY`, AdSense client + the three slot ids. Leave `VITE_ENABLE_BILLING=0` and `VITE_ENABLE_ADMIN_UI=0` until you mean to turn them on. Redeploy after env changes.
6. **Resend** (alerts): GitHub secrets `RESEND_API_KEY`, `ALERT_FROM_EMAIL`, `ALERT_SITE_URL`. Optional `TELEGRAM_BOT_TOKEN`.
7. **Optional API host** (contact form, Razorpay, admin ingest): deploy `backend/` to Railway or Render and set `VITE_API_URL`. Billing stays off until both the API and `VITE_ENABLE_BILLING=1` are set.
8. **Google OAuth** (bookmarks/comments sign-in via Google): Supabase → Authentication → Providers → Google. Magic-link email works once Supabase Auth is configured.
9. **AdSense**: approval plus real numeric ad-unit ids. Empty slot env keeps ads off.
